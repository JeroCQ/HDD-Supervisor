# HDD Supervisor

Browser-operated knowledge assistant for Utah horizontal directional drilling crews. The application uses the user-owned Supabase project as its only backend and Gemini as its only AI provider.

See [`docs/HOW_HDD_RAG_WORKS.md`](docs/HOW_HDD_RAG_WORKS.md) for the architecture and [`docs/CLOUD_TESTING_GUIDE.md`](docs/CLOUD_TESTING_GUIDE.md) for browser-only deployment and verification.
